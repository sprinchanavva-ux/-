## Структура папки

```

├── data/

└── README.md                    # этот файл
```

## Порядок запуска (полный пайплайн с нуля)

Все скрипты запускаются из одной папки, где лежат и они сами, и файлы данных
(проще всего — скопировать все `.py` из `scripts/` и нужный `.json` из `data/`
в одну рабочую директорию перед запуском).

```bash
pip install trafilatura tqdm pymorphy3 pymorphy3-dicts-ru razdel nltk scikit-learn transformers sentencepiece

# 1. Сбор текста (нужен только если добираете новые URL — на готовом corpus.json можно пропустить)
python scraper_fetch_known_urls.py    # вход: urls_to_scrape.json → выход: corpus.json

# 2. Предобработка
python preprocessing.py               # вход: corpus.json → выход: corpus_processed.json

# 3. Количественный анализ (порядок между собой не важен)
python freq_collocations.py           # → freq_colloc_results.json
python topic_modeling.py              # → topic_results.json
python stylometry.py                  # → stylometry_results.json
python sentiment_bert.py              # → sentiment_results_bert.json
```

**Важно:** `sentiment_bert.py` скачивает модель с HuggingFace Hub — нужен
доступ в интернет при первом запуске.
